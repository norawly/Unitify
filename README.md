# Unitify · Schedule

Личный учебный помощник AITU: сайт расписания и карта аудиторий, Telegram-бот
с напоминаниями, дедлайны Moodle, оценки и attendance через Unitify Bridge.
Ранее проект назывался JustSchedule / Schedule; npm-пакет и Worker пока называются `schedule`.

Документация сверена с кодом 27 октября 2026 года. Это описание репозитория,
а не подтверждение текущего состояния облачных сервисов.

Нурали разрешил получателю использовать существующее расширение Unitify Bridge.
Отдельная публикация в Chrome Web Store не нужна: можно собрать ZIP того же
расширения для своего сервера и установить распакованную копию.
**Установленная версия с адресом сервера Нурали не переключается на новый
Cloudflare автоматически.** Для неё нужен пакет с новым адресом либо изменение
механизма выбора сервера. Подробнее — в инструкции запуска.

Репозиторий пока **не универсальный шаблон самостоятельного запуска**:
бот жёстко рассчитан на двух владельцев, backend расширения задан в исходниках.
Для независимой копии одного человека эти места нужно адаптировать.
Документация не меняет доступ или рабочую конфигурацию исходного сервиса.

## Возможности текущей версии

- Сайт: недельная лента на компьютере, свайпы по дням на телефоне, темы, PWA и офлайн-кэш.
- Статистика типовой недели: длительность занятий, предметы, форматы, окна и аудитории.
- Карта C1: поиск кабинета, открытие из пары, мобильные жесты масштаба и перемещения.
- Telegram: следующая пара, день/неделя, изображения расписания и кабинетов,
  напоминания, RU/EN, дедлайны, домашние работы, оценки и attendance.
- Постоянная клавиатура Telegram отделена от временных карточек и сохраняется
  при навигации и ночной очистке.
- Оценки сгруппированы по смыслу, большие журналы разбиты на страницы.
  Явно чужие пустые групповые задания фильтруются в представлении;
  исходные записи и выставленные баллы сохраняются.
- Attendance в карточке пары различает Present, Absent, Waiting for Moodle и NA.
  Сводка и прогноз используют полученные отметки; неизвестные и будущие записи
  не считаются пропусками. Прогноз не гарантирует будущий результат.
- [Закреплённые read-only зрители](docs/demo-access.md) читают данные владельца
  без дополнительных Moodle-запросов и права менять настройки. Это демонстрация,
  не самостоятельная копия сервиса.

## Архитектура

| Путь | Назначение |
|---|---|
| `public/<slug>/schedule.js` | Источник расписания: `window.SCHEDULE` |
| `tools/page.html` | Шаблон страниц; сгенерированные HTML править здесь |
| `tools/build-pages.py` | Страницы, manifests, главная, 404 и robots |
| `tools/export-json.mjs` | JSON расписаний и `people.json` для бота |
| `public/app.js`, `styles.css`, `stats.js` | Календарь и статистика |
| `public/map.js`, `public/map/floors.json` | Карта C1 |
| `public/sw.js` | Офлайн-кэш; `VERSION` управляет сменой кэша |
| `worker/index.js` | HTTP-маршруты, статика, резервный cron |
| `worker/bot.js`, `worker/msgs.js` | Команды, кнопки, карточки и сообщения |
| `worker/access.js`, `worker/db.js` | Доступ владельцев/зрителей, D1 |
| `worker/ticker.js`, `worker/cron.js` | Минутный alarm и фоновые задачи |
| `worker/sched.js`, `academic.js`, `attendance.js` | Учебные расчёты |
| `worker/moodle.js` | Личный iCalendar Moodle |
| `worker/lms-extension.js`, `worker/lms-policy.js` | API и контекст расширения |
| `extension/`, `extension/lib/` | Chrome MV3, парсинг, карточки, политика чтения |
| `migrations/`, `tests/` | SQL-миграции и тесты |
| `wrangler.jsonc` | Worker, Assets, D1, Ticker, cron, лимиты, переменные |

Сайт и API живут в одном Cloudflare Worker. D1 хранит пользователей, владение,
учебные данные и привязки. Основной таймер — SQLite Durable Object `Ticker`,
cron раз в минуту служит страховкой.

`.github/workflows/pages.yml` публикует **только статику** на GitHub Pages.
Сейчас workflow запускает только генератор HTML; он не заменяет полную сборку,
Worker, D1, Telegram и API расширения.

## Локальный запуск

Нужны современный Node.js с `node:sqlite` для тестов и `import.meta.dirname`
для сборки, npm, Python 3, системный `zip`.
Локальная проверка 27 октября 2026: Node.js 26.0.0, Python 3.12.6,
Wrangler 4.151.0; 79 тестов прошли. Это не проверка облака или телефона.

```bash
npm ci
npm run build
npm test
```

Сборка генерирует страницы, JSON, картинки аудиторий и дней,
`public/downloads/unitify-moodle-reader.zip`. Используйте текущий lockfile.

Только сайт:

```bash
python3 -m http.server 8787 --directory public
```

Worker с локальной D1:

```bash
npx wrangler d1 migrations apply DB --local
npx wrangler dev --local --test-scheduled
```

Секреты разработки — в игнорируемом `.dev.vars`. Используйте тестовый токен
или подмену `TG_API`, чтобы не перенастроить webhook рабочего бота.
`DEV_NOW` подменяет время. Локальные секреты не загружаются в Cloudflare автоматически.

## Изменить или добавить расписание

1. Создать `public/<slug>/schedule.js` на основе полного профиля.
2. Задать свои `owner`, `barcode`, `group`, `year`, `period`, `updated`,
   периоды `term`, сокращения `subjects` и занятия `days`.
3. Выполнить `npm run build`, проверить страницу и JSON.
4. Для уже настроенного своего экземпляра — `npm run deploy`.
   Первый запуск — по [инструкции](docs/self-hosting.md).

Slug: строчные латинские буквы, цифры и дефисы, от 1 до 40 символов.
Регистрация ищет непустой `barcode`; формат проверяется в `worker/bot.js`.
В исходных личных профилях баркод может быть пустым.

```js
{ start: "12:00", end: "12:50", subject: "Название предмета",
  type: "practice", // lecture | practice | lab | seminar
  code: "COURSE-CODE", // код курса, не кабинет
  room: "C1.2.232P", building: "Главный корпус", teacher: "Имя преподавателя" }
```

Онлайн-пара: `online: true`. Дни: `mon`–`sun`.
`term.study`, `term.exams`, `term.vacation`, `term.holidays` должны соответствовать
реальному календарю; даты автора не становятся автоматически актуальными для всех.

`aliasOf` берёт базовое расписание другого профиля: не удаляйте базу до переноса
зависимостей. `hidden: true` скрывает профиль с главной, `private: true` также
включает проверку владения в боте. **Это не HTTP-авторизация**: HTML, JS и JSON
из `public/` могут быть доступны по прямой ссылке без отдельной защиты.

## Telegram и Moodle

Команды: `/start`, `/menu`, `/next`, `/today`, `/tomorrow`, `/week`,
`/settings`, `/deadlines`, `/extension`, `/grades`, `/attendance`, `/homework`.
Администратору доступна `/users`; номер аудитории текстом открывает сведения о ней.

Текущий экземпляр допускает ровно два ID из секрета `BOT_ALLOWED_CHAT_IDS`.
Зрители задаются отдельно в `BOT_DEMO_ACCESS`. Переменные `REGISTRATION=closed`
и `MAX_USERS=2` сами по себе не описывают всю модель доступа.

```bash
npx wrangler secret put TELEGRAM_TOKEN
```

На **своём** сервере `/tg/setup` настраивает webhook и Ticker,
`/tg/status` показывает состояние. POST webhook — `/tg/webhook`; секрет
вычисляется из токена, отдельный `WEBHOOK_SECRET` текущим кодом не используется.

Два канала Moodle:

- Личный HTTPS iCalendar с `lms.astanait.edu.kz/calendar/export_execute.php`
  и `authtoken`, отправленный своему боту: сервер читает календарные дедлайны.
- Unitify Bridge: браузер читает задания, статусы сдачи, оценки и attendance
  в авторизованной сессии и передаёт данные и изображения карточек в D1.

Бот показывает сохранённую базу при закрытом ноутбуке. Новые данные расширения
появляются при работающем браузере и открытой вкладке Moodle.
Пароли, cookies, исходный HTML и файлы работ не передаются; Moodle не изменяется.
Точные интервалы и установка — в [README расширения](extension/README.md).

## Карта и телефон

Карта основана на [aitumap](https://github.com/Yuujiso/aitumap), автор Yuujiso.
Сохраняйте атрибуцию и проверяйте условия использования при распространении.

```bash
node tools/editor-server.js
```

Редактор: `http://localhost:8790`, сохраняет `public/map/floors.json`
и резервные копии в `public/map/backups/`. Это локальный инструмент.
Перетаскивание меняет положение, точки — контур; `Ctrl+S` сохраняет, `Ctrl+Z` отменяет.
Повторный импорт через `tools/import-aitumap.py` перезаписывает карту целиком.

iPhone: Safari → «Поделиться» → «На экран Домой». Android: меню установки
поддерживаемого браузера. Это установка сайта: настольное Chrome-расширение
не становится расширением Safari на iPhone.

## Приватность и сопровождение

Не включайте `.dev.vars`, `.wrangler/`, токены, экспорт D1, личные Moodle-ссылки,
ID владельцев и учебные снимки в публичные файлы. Передавайте чистый checkout,
а не всю рабочую папку автора.

Перед изменением облака проверьте аккаунт и ресурсы. Тест или dry-run
не доказывает работу Telegram, Moodle или устройства.
Перенос, диагностика, обновление и резервное копирование:
[docs/self-hosting.md](docs/self-hosting.md).
