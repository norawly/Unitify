# Schedule

Расписания пар: календарь недели на компьютере, свайп по дням на телефоне, карта корпуса,
статистика учебной недели,
ставится на телефон как приложение и работает офлайн.

| Чьё | Адрес |
|---|---|
| Нурали (CS-2411) | https://s.zhengisbay.com/nurali |
| Нурбек | https://s.zhengisbay.com/nurbek |

На https://s.zhengisbay.com — страница выбора. Хостинг — Cloudflare Worker `schedule`
со статикой из `public/`, копия на GitHub Pages.

## Что внутри

| Файл | Зачем |
|---|---|
| `public/<имя>/schedule.js` | **Расписание человека — правится только он** |
| `tools/page.html`          | Шаблон страницы расписания |
| `tools/build-pages.py`     | Собирает `public/<имя>/index.html`, манифесты, страницу выбора и 404 |
| `public/app.js`, `styles.css` | Календарь, карточки пар, оформление — общие для всех |
| `public/stats.js`         | Подсчёт занятий, окон, форматов и кабинетов для статистики |
| `public/map.js`, `map/floors.json` | Карта корпуса C1 |
| `public/sw.js`             | Офлайн-кэш |
| `worker/`                  | Telegram-бот: команды, напоминания, регистрация |
| `tools/export-json.mjs`    | `schedule.js` → `schedule.json` и `people.json` для бота |

## Добавить человека

1. Скопировать `public/nurali/schedule.js` в `public/<имя-или-баркод>/schedule.js`.
2. Поменять `owner`, `group`, `barcode` и пары.
3. `npx wrangler deploy` — страница `s.zhengisbay.com/<имя>` появится сама
   (сборка страниц запускается перед деплоем автоматически).

Полезные поля:

- `barcode: "240614"` — по нему студент входит в бота;
- `hidden: true` — страницы нет на странице выбора, только по прямой ссылке и через бота;
- `aliasOf: "nurali"` — пары берутся у другого человека (одна группа — один набор пар).
  На сайте базовое расписание загружается перед профилем, поэтому изменения в парах
  сразу появляются и на странице с баркодом.

Локально перед просмотром: `python3 tools/build-pages.py`.

## Telegram-бот

Живёт в том же воркере `schedule` (`worker/`), бесплатно на Cloudflare:

- **webhook** `/tg/webhook` — команды и кнопки; чужие запросы без секрета Telegram отбрасываются;
- **cron раз в минуту** — напоминание перед парой, утром пары на день, вечером на завтра,
  предупреждения о праздниках, сессии и каникулах;
- **D1** `schedule-bot` — пользователи, заявки и отметки об отправленном (`migrations/`);
- **Rate limiting** — не больше 20 действий в минуту с одного аккаунта.

**Регистрация по баркоду.** На `/start` бот просит баркод. Есть такой в расписаниях —
сразу показывает пары, нет — отправляет к админу (`ADMIN_CONTACT` в `wrangler.jsonc`).
Первый зарегистрировавшийся становится админом. Мест — `MAX_USERS` (60).
`/users` у админа — список пользователей.

**Команды:** `/today`, `/tomorrow`, `/next`, `/week`, `/settings`, номер кабинета текстом
(`2.232P`) — где он и какие у тебя там пары. Кнопка меню бота открывает сайт как мини-приложение.

**Токен** хранится только в секретах Cloudflare, в репозиторий не попадает:

```bash
npx wrangler secret put TELEGRAM_TOKEN
```

После этого cron сам настроит webhook, команды и описание бота. Не ждать —
открыть https://s.zhengisbay.com/tg/setup (покажет ответ Telegram, без токена).
Проверить, что всё живо: https://s.zhengisbay.com/tg/status — webhook, ошибки Telegram,
число пользователей и время последнего запуска cron.

Сменить токен: `bash tools/set-bot-token.sh`, затем открыть `/tg/setup`.
При смене токена — то же самое, webhook перенастроится автоматически.

**Локальная проверка:** `.dev.vars` с тестовым токеном, `TG_API` на фальшивый сервер
и `DEV_NOW` для подмены времени; `npx wrangler dev --local --test-scheduled`.

## Как поменять расписание

1. Открыть `public/<имя>/schedule.js` и отредактировать нужный день.

   ```js
   { start:"12:00", end:"12:50",
     subject:"Веб-безопасность",
     type:"practice",            // lecture | practice | lab | seminar
     code:"WS53-EN-P115",        // код курса (не кабинет)
     room:"C1.2.232P",           // кабинет
     building:"Главный корпус",  // корпус
     teacher:"Сапаш С.А." }
   ```

   Для онлайн-пары вместо `room`/`building` ставится `online:true`.
   Корпус пишется только если он не главный («Корпус Коркем», «Корпус IEC») — для них
   карта пока не рисуется.
   Поле `updated` вверху файла — дата обновления, видна в подвале сайта.

2. Выложить:

   ```bash
   npx wrangler deploy      # Cloudflare
   git commit -am "update" && git push   # GitHub Pages (деплоится сам)
   ```

## Как это устроено

- **Компьютер** — недельная лента: шесть дней в кадре, прокрутка вбок с примагничиванием
  по дням, стрелками — на неделю вперёд или назад.
- **Телефон** — дни листаются свайпом, вкладки сверху показывают даты текущей недели.
- Подряд идущие пары одного предмета склеиваются в один блок, время округляется
  до целого часа (12:00–12:50 + 13:05–13:55 → «12:00 – 14:00»). Точное время видно в карточке.
- Цвет = тип занятия: лекция, практика, лекция онлайн, практика онлайн.
- Расписание одинаковое каждую неделю, поэтому листается на любое число вперёд.
- Кнопка «Статистика» открывает обзор типовой учебной недели: часы занятий по дням,
  очные и онлайн форматы, время по предметам, окна и частые кабинеты. Время занятий
  считается по реальным интервалам пар, без коротких перерывов; окна считаются
  при промежутке от 60 минут. Экзамены, дедлайны и посещаемость в расчёт не входят.

## Карта корпуса

Планы этажей взяты из [aitumap](https://github.com/Yuujiso/aitumap) (карта корпуса C1,
автор Yuujiso) и переведены в `public/map/floors.json` — 265 помещений на трёх этажах:
номер, тип, контур, плюс подложка стен.

На карте есть контур здания, зоны (санузлы, техпомещения, лестницы, эвакуационные выходы,
спортзал, коворкинг), иконки и крупные подписи блоков C1.1 / C1.2 / C1.3.

Карта открывается кнопкой в шапке и из карточки любой пары — нужный кабинет
находится и подсвечивается сам. Буква на конце номера (L, P, K) при поиске не важна:
`2.221K` найдёт `2.221P` — номер и так уникален. Логика в `public/map.js`.

### Локальный редактор карты

```bash
node tools/editor-server.js      # http://localhost:8790
```

Сохранение пишет в `public/map/floors.json`, прошлая версия копируется в `public/map/backups/`.

| Действие | Как |
|---|---|
| Выбрать кабинет | клик по нему, в списке слева или в 3D |
| Сдвинуть | перетащить выбранный |
| Изменить форму | тянуть точки контура; `Alt`+клик — удалить точку; точка на середине ребра — добавить |
| Новый кабинет | `+ Кабинет` (по точкам, `Enter`) или `+ Прямоугольник` |
| Номер, название, тип, этаж | панель справа |
| Зоны (стены, санузлы, лестницы…) | клик по зоне → тип и заливка в панели справа |
| Отменить / сохранить | `Ctrl+Z` / `Ctrl+S` |

Слева блок «Из расписания» показывает кабинеты, нужные для пар; красные отсутствуют
на карте — клик создаёт заготовку.

Повторный импорт из aitumap (перезаписывает файл целиком):

```bash
python3 tools/import-aitumap.py <путь-к-aitumap>/src/shared/ui/others public/map/floors.json
```
