# Unitify · Moodle Reader — v0.1.0

Расширение Chrome для AITU Moodle. Только чтение учебных данных в уже открытой сессии.

## Установка

1. В Telegram-боте Unitify отправьте `/extension`. Скачайте ZIP на компьютер и распакуйте в постоянную папку.
2. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное», выберите папку с manifest.json.
3. Нажмите значок расширения — откроется компактное меню, без отдельной вкладки. Введите одноразовый код из бота (10 минут, используется один раз).
4. Откройте https://lms.astanait.edu.kz/my/ и войдите как обычно. Нажмите «Обновить» в расширении. Первый сбор может занять несколько минут.

## Что собирается

Доступные курсы, домашние задания со сроками и статусами сдачи, личный журнал оценок (включая старые оценки и комментарии преподавателя), собственные сессии attendance. Структурные селекторы и ID Moodle не зависят от названий предметов. Недоступные по группе задания не обходятся. На неизвестной разметке выводится ошибка, старые данные не стираются.

Первый сбор каждого раздела — история без уведомлений. Затем бот сообщает о новых и изменённых записях. Команды `/grades`, `/attendance`, `/homework` показывают последние записи, полный список и историю — расширение. Отметка «submitted» подавляет напоминания ICS, только если ссылка задания позволяет точно сопоставить его ID. Ручная отметка «Сделал» остаётся независимой.

## Приватность и ограничения

- Нет разрешения cookies, паролей, отдельного входа на сервере, экспорта сессии или чтения файлов работ. Никаких отправок форм, загрузок работ, выставления отметок или изменения Moodle. Обычные просмотры страниц могут попадать в стандартный журнал Moodle.
- После явной привязки передаются только нормализованные учебные данные. Сервер хранит хеш ключа расширения, сами данные и историю изменений (до 500 записей / 90 дней). История в расширении — до 500 изменений. Cookies, пароль, HTML, session keys не являются полями протокола.
- Используется та же сессия Chrome. Проверка при открытии и примерно каждые 10 минут, пока открыта вкладка Moodle; без браузера/действительного входа фонового доступа нет. Уже активный экзамен/редактирование ответа ставит чтение на паузу. Можно поставить паузу вручную.
- Переключатель в верхней части мини-меню отключает новые проверки и передачу боту; уже начатый запрос может завершиться. Пауза сохраняется после закрытия меню и перезапуска браузера. Повторное включение возобновляет работу, сохранённые данные не теряются.
- Время изменения — момент обнаружения, не гарантированное время действия преподавателя. Статус сдачи действителен на последнюю успешную проверку. При истёкшем входе расширение не пытается авторизоваться заново.
- Один запрос Moodle за раз, пауза между запросами, до 180 страниц за проход. Если курсов/работ больше, часть останется непроверенной; интерфейс сообщает об ошибках. Не обещается поддержка неизвестных плагинов и иных версий Moodle без проверки.
- До привязки кодом из разрешённого Telegram-аккаунта никакого автоматического сбора нет. После привязки сначала проверяется, что пользователь вошёл в Moodle. Повторные проверки обращаются к сохранённым прямым ссылкам оценок, attendance и работ, не открывая отдельные вкладки. Курсы обнаруживаются заново раз в сутки, новые задания в курсах — примерно раз в час.
- Между запросами Moodle — 3 секунды (не более 20 в минуту от одного сборщика). Ручной повтор — не раньше двух минут после проверки. При HTTP 429 действует пауза минимум 15 минут с учётом Retry-After, при сетевой ошибке/5xx — минимум 5 минут. Общий неизвестный лимит Moodle для всей вашей активности гарантировать нельзя: обычные вкладки и другие приложения тоже делают запросы.
- Доступ бота по-прежнему закрыт двум разрешённым аккаунтам. ZIP общедоступен, но привязка без кода своего разрешённого Telegram-аккаунта невозможна.
- Можно отозвать подключение в настройках бота или расширении. Это прекращает дальнейшую передачу, но не удаляет уже сохранённые записи. «Очистить локальную историю» удаляет только локальную копию.

## Обновление

Распакуйте новую версию в ту же папку, нажмите обновление расширения на chrome://extensions и перезагрузите вкладку Moodle. Настройки сохранятся. В Chrome Web Store расширение пока не опубликовано, автоматических обновлений нет.

Если сбор не работает: мини-меню → Настройки → Скачать диагностику. Отчёт содержит только состояние, счётчики, время проверок и типы ошибок — без cookies, ключей, оценок, названий предметов и идентификаторов аккаунта. Перед отправкой можно открыть JSON и проверить содержимое.
