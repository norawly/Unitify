# Unitify Bridge · 0.2.0

## Обновление

Замените файлы в ранее выбранной папке расширения. На chrome://extensions нажмите ↻ у Unitify Bridge и перезагрузите вкладку Moodle. Привязка к боту сохранится.

Для первой установки: распакуйте ZIP → chrome://extensions → Режим разработчика → Загрузить распакованное. Получите код командой `/extension` в боте и введите его в мини-меню. Войдите в Moodle обычным способом.

## Работа

- Каждый новый заход в Moodle запускает обновление. Одновременные вкладки объединяются в один проход; до входа и привязки сбора нет.
- До 8 запросов параллельно без искусственных задержек. Известные страницы читаются напрямую, страницы курсов — для поиска новых работ. Скорость зависит от Moodle и числа заданий; 10–20 секунд не гарантируются.
- Результаты и ошибки сохраняются по мере получения. Одна недоступная страница не обнуляет весь сбор.
- Собираются задания с описаниями, сроками и статусами сдачи; оценки, вес, проценты и комментарии; attendance с отметками и баллами.
- В боте: «Оценки» → предмет → карточка всех оценок; «Attendance» → компактная сводка по предметам. Большой журнал разбит на страницы карточки.
- Бот читает сохранённую базу без включённого ноутбука. Новые данные Moodle появляются в ней, когда браузер и Moodle снова открыты.
- Переключатель в мини-меню ставит сбор и передачу на паузу. При HTTP 429 учитывается Retry-After. Во время теста/редактирования ответа сбор останавливается; уже начатые запросы могут завершиться.

## Приватность

Работа идёт в той же сессии Chrome: пароль, cookies, исходный HTML и файлы работ не передаются. Отдельного входа нет. Учебные данные и изображения оценок хранятся приватно в базе бота, не в публичных файлах сайта. Доступ по-прежнему только двум разрешённым аккаунтам.

Moodle не изменяется: нет отправок работ, выставления оценок и отметок attendance. Обычные просмотры могут попадать в журнал Moodle. Данные соответствуют последнему успешному чтению, не гарантированно текущему состоянию сайта.

«Настройки → Скачать диагностику» сохраняет состояние, счётчики и ошибки без ключей, cookies, оценок, названий предметов и ID аккаунта.
