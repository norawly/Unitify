# Unitify Bridge · 0.3.1

## Обновление

Замените файлы в ранее выбранной папке расширения. На chrome://extensions нажмите ↻ у Unitify Bridge и перезагрузите вкладку Moodle. Привязка к боту сохранится.

Для первой установки: распакуйте ZIP → chrome://extensions → Режим разработчика → Загрузить распакованное. Получите код командой `/extension` в боте и введите его в мини-меню. Войдите в Moodle обычным способом.

## Работа

- Первый заход после привязки запускает сбор. Далее — не чаще одного раза в 30 минут и только при открытой вкладке Moodle. Перезагрузка страницы, другие вкладки, ручное обновление и переключатель паузы этот интервал не обходят. Таймер сохраняется между перезапусками браузера. Проверка наступившего интервала — раз в 5 минут, поэтому фактический промежуток может быть чуть длиннее.
- Не более двух запросов одновременно, начало запросов разнесено минимум на 900 мс. Сохранённые ссылки читаются напрямую; страницы курсов для поиска новых заданий проверяются раз в 6 часов, либо используются бесплатно, когда пользователь сам открыл курс.
- Обычно перечитываются только несданные/актуальные домашки. Уже сданные и просроченные более недели задания проверяются при суточной сверке. Задание, которое открыто сейчас, читается из самой страницы без дополнительного запроса.
- Оценки — только с 09:00 до 23:00 по Астане. Attendance — первая дневная проверка всех предметов, далее только предметы, у которых пара начинается через 30 минут, идёт или закончилась не более 90 минут назад. Сопоставление по названию курса и официальным английским названиям из расписания; неизвестные совпадения не угадываются. Ночью читаются только задания. На каникулах вне первой дневной проверки attendance не опрашивается.
- Результаты и ошибки сохраняются по мере получения. Одна недоступная страница не обнуляет весь сбор.
- Собираются задания с описаниями, сроками и статусами сдачи; оценки, вес, проценты и комментарии; attendance с отметками и баллами.
- В боте: «Оценки» → предмет → карточка всех оценок; «Attendance» → компактная сводка по предметам. Большой журнал разбит на страницы карточки.
- В карточке оценки разделены: Register / totals — отдельные плитки, Attendance — отдельная полоса, Exams & checkpoints и Assignments & practice — отдельные списки с естественной нумерацией. Служебные подписи Moodle не добавляются к названию и баллу.
- Группа берётся из расписания, привязанного к Telegram. Пустые задания, явно адресованные другой группе, скрываются только в представлении, без удаления исходных записей. Общие задания, неоднозначные групповые списки и любые выставленные баллы (включая 0) сохраняются. Если группа неизвестна, фильтра нет.
- Бот читает сохранённую базу без включённого ноутбука. Новые данные Moodle появляются в ней, когда браузер и Moodle снова открыты.
- Переключатель в мини-меню ставит сбор и передачу на паузу. При HTTP 403/429, ошибке сервера или сети — пауза минимум 30 минут, более длинный Retry-After также учитывается. Во время теста/редактирования ответа сбор останавливается; уже начатые запросы могут завершиться.

## Обновления

Сервер передаёт расписание, номер свежей версии и ограниченные числовые настройки частоты. Эти данные обновляются автоматически при синхронизации; никакой удалённый код не выполняется. При появлении версии новее установленной в мини-меню появится кнопка скачивания.

Сам код распакованного расширения Chrome автоматически не заменяет. Для обычных пользователей macOS/Windows штатные автоматические обновления требуют публикации в Chrome Web Store. Эта версия туда не публикуется: пока нужно заменить файлы в той же папке и один раз нажать ↻ в chrome://extensions.

Подготовка публикации и подключения: `docs/chrome-web-store.md` в репозитории. Публикация в магазине не открывает доступ к закрытому боту. Адрес HTTPS-сервера остаётся тем же; он не является секретом.

## Приватность

Работа идёт в той же сессии Chrome: пароль, cookies, исходный HTML и файлы работ не передаются. Отдельного входа нет. Учебные данные и изображения оценок хранятся приватно в базе бота, не в публичных файлах сайта. Доступ по-прежнему только двум разрешённым аккаунтам.

Moodle не изменяется: нет отправок работ, выставления оценок и отметок attendance. Обычные просмотры могут попадать в журнал Moodle. Данные соответствуют последнему успешному чтению, не гарантированно текущему состоянию сайта.

«Настройки → Скачать диагностику» сохраняет состояние, счётчики и ошибки без ключей, cookies, оценок, названий предметов и ID аккаунта.
